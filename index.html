공식몰 후기는 페이지 단위로 실시간 요청합니다.
Google Apps Script 서버가 공식몰에서 현재 요청한 페이지의 후기 5건만 가져와 표시합니다. 후기 본문과 고객 사진을 제품자료실이나 태블릿에 대량 저장하지 않습니다. 웹 앱 배포 URL은 config.js에 설정해야 합니다.
⚠ 제품 사진 업로드는 시제품 테스트용으로만 권장합니다. 브라우저 저장 공간이 제한되어 있으므로 중요한 자료는 JSON 파일로 수시로 백업하세요. 공식몰 사진·상세 이미지는 온라인 연결이 필요합니다. 공식몰 후기는 Google Apps Script 배포 URL과 인터넷 연결이 필요하며, PC와 태블릿 간 자동 동기화는 아직 지원하지 않습니다.
